# The-Role-of-Luck-in-Educational-Achievement
The Role of Luck in Educational Achievement
This file accompanies the replication material for the paper "The Role of Luck in Educational Achievement."

Its purpose is to help readers interested in replicating the reported analysis or examining the analysis decisions.

There are 5 files:

Online_Appendix_LuckQuotes.pdf: This is what the manuscript refers to as Online Appendix. It contains all excerpts from the interviews that contain definitions of luck.

ESS8e02_3-ESS9e03_2-ESS10-ESS11.csv: These are waves 8 through 11 of the European Social Survey (ESS).

luck_definitions_102326.dta: This is the Stata data file containing the original luck definition codings.

luck_events_102326.dta: This is the Stata data file containing the original chance event codings.

ROL.do: This is the Stata code that reproduces all analysis results reported in the paper, except for the individual-level demographics reported in aggregate in section 4.1 which are not disclosed to prevent identification, following our Ethics protocol. The file has three parts. Part 1 performs the descriptive analysis of the ESS and reproduces the Table 1 figures as well as related statistics mentioned in the main text. Part 2 predicts educational outcomes in the ESS and reproduces Table A1 in Appendix A as well as related quantitative results mentioned in the main text and Appendix A. Part 3 reproduces the collapsing of the interviewee definition codings as detailed in the main manuscript. It also reproduces the agreement coding of the two coders. It reproduces Figures 1, 2 and 3.
