# The-Role-of-Luck-in-Educational-Achievement
The Role of Luck in Educational Achievement

This file accompanies the replication material for the paper "The Role of Luck in Educational Achievement."
Its purpose is to help readers interested in replicating the reported analysis or examining the analysis decisions.

There are 4 files:
1. Online_Appendix_LuckQuotes.pdf: This is what the manuscript refers to as Online Appendix. It contains all excerpts from the interviews that contain definitions of luck.
2. luck_definitions_102326.dta: This is the Stata data file containing the original luck definition codings.
3. luck_events_102326.dta: This is the Stata data file containing the original chance event codings.
4. ROL.do: This is the Stata code that reproduces all analysis results reported in the paper, except for the individual-level demographics reported in aggregate in section 4.1 which are not disclosed to prevent identification, following our Ethics protocol. The file has three parts. Part 1 performs the descriptive analysis of the ESS and reproduces the Table 1 figures as well as related statistics mentioned in the main text. Part 2 predicts educational outcomes in the ESS and reproduces Table A1 in Appendix A as well as related quantitative results mentioned in the main text and Appendix A. Part 3 reproduces the collapsing of the interviewee definition codings as detailed in the main manuscript. It also reproduces the agreement coding of the two coders. It reproduces Figures 1, 2 and 3.

The analysis additionally uses data from the European Social Survey (ESS), Rounds 8–11. The following editions were used:

ESS Round 8, edition 2.3: https://doi.org/10.21338/ess8e02_3
ESS Round 9, edition 3.2: https://doi.org/10.21338/ess9e03_2
ESS Round 10, edition 3.2: https://doi.org/10.21338/ess10e03_2
ESS Round 11, edition 2.0: https://doi.org/10.21338/ess11e02_0

The original ESS data are not included in this repository. They can be obtained from the ESS using the links above.
